## Agent Interface

**Your agents work as a team. You stay in the decisions.**

Run Claude Code, Codex and OpenCode in one native workspace. See which agent needs you, follow its progress, and discuss plans, documents and results beside the work.

**[Try Agent Interface →](https://agentinterface.dev/)** · [Install](https://agentinterface.dev/#install) · [Source code](https://github.com/eandualem/agent-interface)

## AI inside applications

### Assistant Runtime + Design Studio

<a href="https://github.com/eandualem/design-studio"><img src="https://raw.githubusercontent.com/eandualem/design-studio/main/public/screenshot.png" alt="Design Studio with a document, Mermaid diagram and assistant editing actions" width="800"></a>

**Assistant Runtime** supplies conversations, streaming, voice and tool requests for applications. **Design Studio** shows it in use: an assistant edits Markdown and Mermaid diagrams directly in a document editor, with rendering feedback to help repair diagrams.

<sub>Pydantic AI · FastAPI · Socket.IO · Next.js · XState</sub><br>
[Assistant Runtime](https://github.com/eandualem/assistant-runtime) · [Design Studio](https://github.com/eandualem/design-studio)

**[XState MCP](https://github.com/eandualem/xstate-mcp)** gives coding agents access to a running application's state machines. Inspect actors, context and event history, check which transitions are allowed, and send events through explicit write controls.

### Decision Arena

Watch a race · 28s

https://github.com/user-attachments/assets/f500dfc3-a4b5-48f8-b9f3-234fac9e9d74

How it works · 4min

https://github.com/user-attachments/assets/06496c80-968b-4544-a246-360d391c66fb
